# Audit evidence package

This directory is the submitted archive for the SWARM launch-report checks on
9 October 2026. The worker excludes `artifacts/` from Git, so the report links to
this ordinary repository directory. Capture records retain their original
`artifacts/evidence/...` paths; the corresponding files are archived here as
`docs/audit/evidence/...` without changing response bodies.

- `swarm.listing-draft.json` is the authoritative listing handoff. The website's
  public/download copies are generated by `web/scripts/sync-report.mjs`.
- `verification/Swarm.standard-input.json` is the source-verification input from
  Sourcify, checked against local source.
- `evidence/chain-snapshot*.json` contain exact requests and responses from the
  two public RPCs at block 26,156,668; `verification.json` records local comparison.
- `evidence/requests.json` identifies live HTTP captures and their SHA-256 hashes.
- `evidence/live-browser.json` records a separate rendered live-site branding check.
- `evidence/browser-review.json` records the production-export inspection and
  mocked-wallet tests. Screenshots are observations, not independent certification.
- `validation.md` consolidates commands, Better Interface findings and limitations.

Run scripts **from the repository root**, as documented in the root README.
Reproduction outputs go into `artifacts/`; `verify-build.py` also refreshes
`docs/abi/`. The archived inputs are used when a fresh capture is not present.
Do not substitute a new block's data into the dated report without updating its
block number, hash, observed values and evidence notes together.

Browser scripts use external Playwright/Chromium, close their own foreground
preview/browser and never access a real wallet. Wallet confirmation tests use
an explicit fixture account/provider. They do not demonstrate an executed
mainnet trade. No screenshots from a mock state are labeled as live chain proof.
